# Lancer Hover Translate

Модуль Foundry VTT v13: наводишь курсор на английский абзац в листе предмета,
актёра, компендиума или журнала — рядом с курсором всплывает панель с русским
переводом.

Панель состоит из двух частей:

* **Термины.** Найденные в абзаце термины Лансера из локального словаря
  `data/glossary.json`. Работает офлайн и мгновенно.
* **Перевод абзаца.** Машинный перевод всего блока целиком. Нужна внешняя
  служба; без неё модуль показывает только термины.

## Установка

По манифесту:

```
https://raw.githubusercontent.com/Edurd-rgb/lancer-hover-translate/refs/heads/main/module.json
```

## Настройки

| Настройка | Область | Что делает |
| --- | --- | --- |
| Включить подсказки | клиент | Общий выключатель, у каждого игрока свой. См. «Выключить на ходу». |
| Способ вызова | клиент | Просто наведение или наведение с зажатым Alt / Ctrl / Shift. |
| Задержка | клиент | Сколько курсор должен постоять на абзаце. По умолчанию 350 мс. |
| Словарь терминов | клиент | Показывать верхнюю секцию панели. |
| Не переводить термины Лансера | клиент | Оставлять термины в переводе по-английски. По умолчанию включено. |
| Служба перевода | мир | `Только словарь`, `MyMemory`, `LibreTranslate` или `Google Cloud Translation`. |
| Почта для MyMemory | мир | Необязательно. Поднимает дневную норму с 5000 до 50 000 символов. |
| Адрес LibreTranslate | мир | Свой сервер или публичный инстанс. |
| API-ключ | мир | Обязателен для Google, необязателен для LibreTranslate. |
| Язык перевода | мир | Код языка, по умолчанию `ru`. |
| Предел длины абзаца | мир | Более длинный текст обрезается перед отправкой. |

## Выключить на ходу

Перевод отключается лично каждым игроком и прямо посреди игры, лезть в меню
настроек не нужно:

* **Кнопка в панели инструментов сцены** — значок перевода в группе токенов,
  работает как переключатель и подсвечивается, когда перевод включён.
* **Горячая клавиша** — по умолчанию `Alt+T`, переназначается в стандартном
  разделе «Настройка управления». В отличие от кнопки, работает и там, где сцены
  нет вовсе, например при чтении журнала.

Оба способа меняют одну и ту же клиентскую настройку, поэтому переключатель,
клавиша и меню всегда показывают одно состояние. Если панель перевода уже висит
на экране в момент выключения, она гаснет сразу.

Настройка личная: выключение у игрока никак не затрагивает остальной стол.

### Про службу перевода

Модуль исполняется в браузере игрока, серверной части у него нет — значит,
служба перевода обязана отдавать **CORS-заголовки**. Это сразу отсекает DeepL и
почти все публичные зеркала LibreTranslate. Рабочих вариантов три:

* **MyMemory** — бесплатно, без ключа, без регистрации и без привязки карты.
  Норма: 5000 символов в день с одного адреса, 50 000 если указать почту в
  настройках. Квота считается по IP, то есть у каждого игрока своя. Запрос
  ограничен 500 символами, поэтому длинные абзацы модуль сам режет по границам
  предложений и склеивает ответ обратно.
* **LibreTranslate**, развёрнутый у себя — без ключа, без лимитов, запросы никуда
  наружу не уходят. Требует Docker и адрес, доступный **браузерам всех игроков**:
  `localhost` увидит только ГМ.
* **Google Cloud Translation** — заметно лучше качеством, но требует проект в
  Google Cloud с привязанным биллингом, даже ради бесплатных 500 000 символов в
  месяц.

Публичный `libretranslate.com` с некоторых пор требует платный ключ, так что
адрес по умолчанию в настройке сам по себе не работает.

**MyMemory стоит по умолчанию**, поэтому сразу после установки перевод работает,
ничего настраивать не нужно. Обратная сторона: текст абзаца уходит из браузера
игрока во внешний сервис. Если это нежелательно — переключите службу на «Только
словарь», тогда модуль работает полностью офлайн.

### Чего ждать от машинного перевода

Терминологию Лансера служба не знает и переводит буквально: `Grit` становится
«зернистостью», `hard cover` — «жёстким покрытием».

Поэтому термины по умолчанию **до перевода прячутся** за плейсхолдеры и
возвращаются в текст по-английски, а их значения показываются строкой выше.
Разница на одной и той же фразе:

```
без защиты терминов:
  ...стать ослабленной до конца хода и получить жесткое покрытие против дальних атак.

с защитой терминов (по умолчанию):
  Impaired   — Ослаблен
  Hard Cover — Полное укрытие
  ...стать Impaired до конца хода и получить Hard Cover против дальних атак.
```

Маркер `#0#` выбран не наугад: проверено, что он переживает перевод неизменным и
не встречается в текстах Лансера. Если служба его всё же покалечит, модуль
оставит фрагмент как есть, а не сломает подсказку.

Отключается настройкой «Не переводить термины Лансера», если предпочитаете
сплошной русский текст со всеми его артефактами.

Настройки службы имеют область «мир», то есть одна настройка обслуживает весь
стол. Обратная сторона: **API-ключ читается любым подключённым клиентом.** Если
это неприемлемо, поднимайте LibreTranslate без ключа.

Переводы кэшируются в `localStorage` браузера (до 1500 записей), поэтому один и
тот же абзац уходит в службу единожды.

## Что модуль не трогает

Чат, боковую панель и ярлыки интерфейса — там короткие подписи, на которых
всплывающая панель только мешает. Также никогда не срабатывает внутри полей
ввода, `contenteditable` и редакторов ProseMirror, чтобы не лезть поверх набора
текста.

Абзац пропускается, если в нём меньше четырёх латинских букв или кириллицы в нём
не меньше латиницы — то есть уже переведённый текст подсказку не вызывает.

## Словарь

`data/glossary.json` — плоский объект `{"English term": "русский перевод"}`.
Поиск нечувствителен к регистру, длинные термины имеют приоритет над короткими
(`Armor Piercing` находится раньше, чем `Armor`), совпадение только по границам
слова: `Overshielding` не считается за `Overshield`.

Поставляемый набор — стартовый, около 180 терминов: статусы, действия,
характеристики, теги оружия, типы урона, снаряжение, НИП и боевые понятия.
Правьте его под терминологию своего стола.

Добавить термины на лету, не трогая файл:

```js
game.modules.get("lancer-hover-translate").api.extendGlossary({
  "Sitrep": "Обстановка",
  "Exotic Gear": "Экзотическое снаряжение"
});
```

## API

```js
const api = game.modules.get("lancer-hover-translate").api;
api.toggle();                 // переключить; api.toggle(false) — выключить
api.isEnabled();              // включён ли перевод у этого игрока
api.findTerms("text");        // термины, найденные в строке
api.translate("text");        // перевод через настроенную службу (с кэшем)
api.extendGlossary({ ... });  // дополнить словарь
api.clearCache();             // сбросить кэш переводов
api.stats();                  // { glossary, cache }
```

## Релиз

Как и в остальных модулях: пуш в `main`, затем релиз с тегом `vX.Y.Z`.
Workflow сверяет тег с полем `version` в `module.json` и падает при
расхождении, подставляет URL и собирает `module.zip` с манифестом в корне
архива. Тег обязан указывать на коммит, где `version` уже исправлена.
